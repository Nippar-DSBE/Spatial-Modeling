# Demo and media

The owner added a demo to the published main branch's [README Demo section](../../README.md#demo). It is hosted as a GitHub user attachment, not as a video file in this directory. Keep the existing URL and embed intact when editing documentation:

https://github.com/user-attachments/assets/19affeeb-1af6-4fb2-a602-575a23891cde

The demo is illustrative; it is not a complete device-regression record. The owner's confirmed operations and remaining validation are tracked separately in [Device testing](../DEVICE_TESTING.md#verification-record). In particular, Boolean result correctness, long-duration stability and detailed performance are not established by the demo.

Additional screenshots or recordings can be added here or linked from README. Check media for personal surroundings, notifications, account information and redistribution rights before sharing. No SolidCraft UI, theme, logo or other third-party brand asset is included in the app source.

The existing v0.1.0 tag and Release are historical snapshots. The README demo was added to main after that release; updating main's documentation does not require replacing the tag or editing the Release.
